⚙️ How It Works

Layer 1 — DNS

Custom Domain

Wildcard A record *.yourdomain.com points to your VPS IP. All subdomains resolve to the same server.

Layer 2 — Firewall

UFW

Only ports 22 (SSH), 80, 443, 81, and 3478 (Nextcloud Talk) are open. All other ports are blocked by default.

Layer 3 — Brute Force

Fail2Ban

Monitors SSH and web logs. Auto-bans IPs that exceed login failure thresholds using Docker-aware iptables rules.

Layer 4 — Proxy

Nginx Proxy Manager

Routes each subdomain to the correct container by name. Handles Let's Encrypt SSL for all services automatically.

Layer 5 — Containers

Docker (npm_default)

All services run isolated in Docker. Reachable only through NPM — no container is directly exposed to the internet.
